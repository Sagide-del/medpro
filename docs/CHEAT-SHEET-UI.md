# Student cheat sheets

Cheat Sheets use a dedicated topic-filtered, searchable library and `?id=` reading view. The reader resembles a printed revision sheet: compact clinical headings, key-point bullets, explicit caution blocks and two columns on desktop. Mobile uses one column. Source citations remain in a small Reference footer; raw generation metadata and repetitive positive editorial source framing are not displayed.

Tables render only from explicit, well-formed Markdown tables in published section text. Invalid table-like text remains visible as text, with no inferred cells or clinical values. Numbered source sequences retain their numbers; other clinical points retain order, values, units and qualifications. This is presentation formatting, not automatic clinical summarization.

Print / Save PDF invokes the browser print dialog with navigation, app controls and the site footer hidden. The sheet title, student track, clinical sections and references remain visible. Long sheets can print over multiple pages; the UI does not claim all content fits on one page.

Future source-grounded cheat-sheet drafts are instructed to use concise direct clinical language, one point per line, and source-backed comparison tables only. Evidence validation, scope screening and human publication review remain required.
